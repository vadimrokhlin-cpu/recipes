# מתכונים

אפליקציית מתכונים אישית לטלפון (PWA). הקוד והנתונים שלי, בלי תלות באפליקציה של מישהו אחר.

- `docs/`: האפליקציה. `core.js` הוא הלוגיקה (קריאת מצרכים וכמויות), `app.js` המסכים והשמירה.
- `apps-script/Code.gs`: השרת, סקריפט בחשבון Google שלי.
- `test/`: בדיקות. הרצה: `node test/test_core.js` ו-`node test/test_sync.js`.

## נתונים
כל מתכון נשמר בטלפון (IndexedDB, האפליקציה עובדת גם בלי אינטרנט), ומסתנכרן כקובץ JSON אחד
בתיקייה "מתכונים" בדרייב, כולל התמונה. בהתנגשות מנצחת העריכה המאוחרת. אפשר גם לייצא ולייבא
גיבוי במסך ההגדרות. כל כמות נשמרת כמספר עם יחידה, לצד השורה המקורית.

## עדכון גרסה
כל שינוי בקבצים ב-`docs/` דורש העלאת מספר הגרסה של `CACHE` ב-`docs/sw.js`.
הדומיין ב-GitHub Pages משותף עם אפליקציית הקניות, לכן שמות המטמון ומסד הנתונים מתחילים ב-`recipes-`.

## שלבים
1. מסכי בית, מתכון והוספה ידנית (בוצע)
2. ייבוא מ-Google Keep
3. התאמת כמויות (לפי מנות ולפי מצרך) ומצב בישול
4. שליחה לרשימת הקניות ו"מזמן לא הכנת"
5. ייבוא מקישור ומצילום
